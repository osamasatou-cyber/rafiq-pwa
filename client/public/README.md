# الرفيق - Begleiter - Companion

تطبيق تتبّع عادات فاخر بثلاث لغات (عربي/ألماني/إنجليزي).

## ✨ المميزات

- **ثلاث لغات:** عربي + Deutsch + English (تبديل من الإعدادات)
- **اتجاه RTL/LTR تلقائي** حسب اللغة
- **5 مراحل لإنشاء العادات:** الجذور، التصميم، المرونة، الأولوية، التبسيط
- **مواعيد محدّدة بالوقت** + إشعارات تذكير
- **تقويم مواعيد منفصل** (لمرة واحدة + دورية: يومي/أسبوعي/شهري/سنوي)
- **إحصائيات فاخرة:** إجمالي الإنجازات، إجمالي المدة، رسم خطي أسبوعي، معدّل يومي
- **6 أوسمة قابلة للكسب**
- **يعمل أوفلاين** (PWA)
- **بياناتك محفوظة محلياً** (تصدير/استيراد للنقل)

## 🚀 النشر على Netlify Drop

1. استخرج هذا المجلد
2. روح https://app.netlify.com/drop
3. اسحب مجلد `pwa` كاملاً
4. الرابط يجهز فوراً

## 📲 التركيب على الجوال

- **Android:** Chrome → القائمة → "تثبيت التطبيق"
- **iPhone:** Safari → مشاركة → "Add to Home Screen"
